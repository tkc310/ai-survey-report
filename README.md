# AI Survey Report

## 前回からの主な変化
1. **デザインの UI 1位が Fable 5.2（1393）に移った。** フラッグシップは Fable（xHigh）/ Wonder（max）/ Astra（xhigh）。WebDev（ページ日付 11/23）の 1位は Fable（xHigh、1822）のまま。複雑なコーディングのコスパは Neon を xHigh にした。FrontierCode の xhigh の点数は未公開。
2. **pstack の節を外し、AI 駆動開発のトレンドを入れた。** 今週は Claude Ship（11/23、PR のレビューと承認方針）。映像・音声・画像の節は初掲載で、品質の投票と、10月の推定トラフィックは並びが違う。
3. ニュース（11/21〜11/28）: Z.ai の GLM-5.4、ChatGPT のチャットタブへの GPT-6.2。Carbon の導入価格 $2/$10 は 11/30 まで。
