### ハーネス・ガードレール

- **Claude Ship（Anthropic, 11/23、ベータ）**: GitHub 上のプルリクエストを、レビューし、直し、チームがリポジトリに書いた承認方針で通すかを決める。中身は、一般提供済みの Code Review と、ベータの PR Steward、Claude Approvals。PR Steward は落ちた CI、コンフリクト、レビューコメントに手を入れ、マージはしない。毎 push のあと、何を変えたかと戻し方をコメントする。`@claude stop` で手を引く。Claude Approvals は、方針が許す定型の変更だけを承認し、それ以外は人に回す。公式は、まず observe-only で様子を見てから、ブランチ保護に組み込むよう勧めている。対象は Claude Team と Enterprise の GitHub リポジトリ。利用はトークン課金。Zero Data Retention、HIPAA 構成、顧客管理の暗号鍵では使えない。設定は変えていない。試すなら、公式が書く observe-only から。Yahoo!ニュース級の日本語記事は確認していない。TechCrunch が 11/23 に報じた。[B1][B2]
