### 選定理由（1モデル1行）
**文章作成・判断**
- Opus 5.5: GDPval-AA v2.1 で 1846 と表中トップ。$4/$20 で Opus 5 より 20% 安い [A1]
- Gemini 4 Argon: Vals Index 1位で、文体指示への追従と簡潔さが改善 [G1]
- GPT-6 Astra: GPT-6 世代の最上位。$10/$50 と高価 [O1][O2]
- Sonnet 5.5: $2/$10 でコンテキスト 1M。GDPval-AA 1840 は Opus にほぼ並ぶ [A2][A3]
- GPT-6.1 Sol: $2/$10、キャッシュ入力 $0.10 [O1] または $0.20 [O3]（料金ページとモデルページで不一致）
- Grok 4.7: $2/$6 と出力単価が最も安い。コンテキスト 500K [X1]
- Fable 5.1（Claude 限定）: 旧フラッグシップ。$10/$50 と高く、GDPval-AA 1735 で Opus 5.5 を下回る [A1][A2]

**コーディング**
- Opus 5.5: Terminal-Bench 4.0 66.4%、CursorBench 4.0 57.8% [A1]
- Grok 4.7: コーディング/エージェント向けのフロンティアモデル。$2/$6。Cursor と Grok Build では Fast 版も使える [X1]
- GPT-6 Astra: Terminal-Bench 4.0 57.9%、FrontierCode 53.3% [A1]
- GPT-6.1 Sol: Sol は「複雑なコーディングとエージェント向け」の位置づけ。$2/$10 [O1][O3]
- Sonnet 5.5: Terminal-Bench 4.0 70.6%（Haiku 5.5 発表時の参考値）。キャッシュ読み取りが半額になりエージェント作業で約 20% 安い [A3]
- Haiku 5.5（Claude 限定）: $0.10/$0.50 で FrontierCode 46.4%。小さく切った作業やサブエージェント向け [A3]

**複雑なコーディング**
- Opus 5.5: FrontierCode v1.1 54.4%。長時間のエージェント型コーディング向け [A1][A2]
- Gemini 4 Argon: 大規模コードベースのリファクタ事例あり（Chromium）。入出力合計 1M トークン [G1]
- GPT-6 Astra: Terminal-Bench-Science 64.6% と科学系の長いタスクに強い [A1]
- Argon（コスパ枠）: 11/30 までは導入価格 $2/$10（以降は $4/$20）[G1]
- Fable 5.1（Claude 限定）: Terminal-Bench 55.8%。Opus 5.5 より性能が低く価格は高いので、3位扱い [A1]

**レビュー**
- Opus 5.5 / Astra / Argon: 上の各ベンチで上位の3モデル。Argon はセキュリティ監査の実績（Wiz）も公表 [A1][G1]
- Sonnet 5.5 / GPT-6.1 Sol / Grok 4.7: $2 前後の入力単価で大量の差分レビューを回せる [A2][O1][X1]

**オーケストレーション**
- Opus 5.5: AutomationBench 40.0%、OSWorld 2.1 81.8%（部分点込み）[A1]
- GPT-6 Astra: AutomationBench 41.4% と表中最高 [A1]
- Gemini 4 Argon: Antigravity でのマルチエージェントループの事例が多い [G1]
- GPT-6.1 Sol: 安価でエージェント向け。ただし最上位級ではない [O1][O3]
- Haiku 5.5（Claude 限定）: Anthropic 自身が Opus/Sonnet のサブエージェントとして推奨 [A3]

## C. 簡潔な AI ニュース（過去7日: 10/9〜10/16）

基準: X のトレンドや Yahoo!ニュースで話題になる水準のものだけ。

### 新モデル発表
- **Muse Wonder / Muse Wonder Full（Meta, 10/12）**: Meta の新しいフロンティアモデル。コンテキストは 1M。Muse Wonder は API で $4/$20、Full は Muse Code の有料プラン限定。Meta は DeepSWE などのコーディング系ベンチで首位だと発表している。[M2]
- **Gemini 4 Argon GA（Google, 10/13）**: Vals Index 1位のフロンティアモデルが一般提供になった。11/30 までの導入価格は $2/$10。[G1]
- **Muse Spark Open（Meta, 10/15）**: 総パラメータ 816B（アクティブ 42B）、コンテキスト 1M のオープンウェイトモデル。M5 Ultra 搭載の Mac Studio 2台でローカル実行でき、Hugging Face で配布。[M1]

### TypeScript エコシステム
- **Bun に `bun lint` が組み込まれた（10/12 に main へマージ）**: ESLint・typescript-eslint などのルール 1,000 以上を内蔵し、既存の ESLint / oxlint の設定をそのまま読む。型を使うルールは `typescript` パッケージなしで動く。安定版の v1.4.3 にはまだ入っていない。[B1]

### 注目のフレームワーク・ライブラリ・言語・サービス・ツール
- **TanStack Start 1.0 安定版（10/13）**: React と Solid 向けのフルスタックフレームワークが正式版になった。型安全なルーティング、SSR、ストリーミング、サーバー関数を持つ。Cloudflare、Netlify、Vercel などがパートナー。[S1]
- **Handwired（Cheng Lou）**: 普通の JavaScript のコードを、学習なしで微分可能なニューラルネットに変換する実験的なプロジェクト。ブラウザ（JS / WebGPU）で動くデモが公開されている。[H1]

### その他話題性の高いもの
- **The X Subscription（xAI）**: Grok・Grok Bot・Cursor・X Premium をまとめた1つのプラン。Premium は月 $30 で、従来の SuperGrok + Cursor Pro + X Premium+（計 $90 相当）を含む。[X2]

> Claude Haiku 5.5 と GPT-6 for everyone（いずれも 10/7）は過去7日より前なので、ニュースから外した（A の推奨には反映済み）。
