### 選定理由（1モデル1行）
**文章作成・判断**
- Opus 5.5: GDPval-AA v2.1 で 1846 と表中トップ。$4/$20 で Opus 5 より 20% 安い [A1]
- Gemini 4 Argon: Vals Index 1位。文体指示への追従と簡潔さが改善 [G1]
- GPT-6 Astra: GPT-6 世代の最上位。$10/$50 と高価 [O1][O2]
- Sonnet 5.5: $2/$10 でコンテキスト 1M。GDPval-AA 1844 は Opus にほぼ並ぶ [A4]
- GPT-6.1 Sol: $2/$10、キャッシュ入力 $0.10。公式は「Astra の約 1/5 の価格で近い知能」と位置づける [O1][O4]
- Grok 4.7: $2/$6 と出力単価が最も安い（200K トークン未満）。コンテキスト 500K [X1][X2]
- Fable 5.1（Claude 限定）: 旧フラッグシップ。$10/$50 と高く、GDPval-AA 1735 で Opus 5.5 を下回る [A1][A5]
- Muse Wonder（検討、表外）: API は $4/$20・1M。AA Intelligence Index 52 で Opus 58 / Astra 53 を下回る。Full は GDPval-AA 1857 と Opus に近いが Muse Code の有料プラン限定でトークン課金がないため、文章作成の API 推奨には入れない [M1][M2][M3]

**コーディング**
- Opus 5.5: Terminal-Bench 4.0 66.4%、CursorBench 4.0 57.8%、FrontierCode v1.1 54.4% [A1]
- Grok 4.7: コーディング/エージェント向けのフロンティアモデル。$2/$6。Cursor と Grok Build では Fast 版も使える [X1]
- GPT-6 Astra: Terminal-Bench 4.0 57.9%、FrontierCode 53.3% [A1]
- GPT-6.1 Sol: 「複雑なコーディングとエージェント向け」の位置づけ。$2/$10 [O3][O4]
- Sonnet 5.5: Terminal-Bench 4.0 70.6%（表中最高）。キャッシュ読み取り $0.10 でエージェント作業が約 20% 安い [A3][A4]
- Haiku 5.5（Claude 限定）: $0.10/$0.50（プロンプト 100k 以下）で FrontierCode 46.4%。小さく切った作業やサブエージェント向け [A3]
- Muse Wonder（検討、表外）: DeepSWE 1.1 は 78.8 と Opus（74.2）・Astra（74.1）を上回るが、Terminal-Bench 4.0-AA は 52.0 で Opus 66.4 / Astra 57.9 に届かない。同じ $4/$20 なら日常コーディングは Opus / Grok を優先する [M1][A1]

**複雑なコーディング**
- Opus 5.5: FrontierCode v1.1 54.4%。長時間のエージェント型コーディング向け [A1][A2]
- Gemini 4 Argon: Chromium の大規模リファクタ事例あり。入出力合計 1M トークン [G1]
- Muse Wonder: DeepSWE 1.1 78.8、SWE-Marathon 53.1（Opus は 74.2 / 46.3、Astra は 74.1 / 42.5）。超長期のリポジトリ作業で公式比較表の首位級。API は $4/$20・1M。Full（DeepSWE 79.0、SWE-Marathon 57.5）は Muse Code の Power $50 / Maximum $200 限定なので表には入れない [M1][M2]
- Argon（コスパ枠）: 11/30 までは導入価格 $2/$10（以降は $4/$20）[G1][G2]
- Fable 5.1（Claude 限定）: Terminal-Bench 55.8%。Opus 5.5 より性能が低く価格は高いので、3位扱い [A1]

**レビュー**
- Opus 5.5 / Astra / Argon: 上の各ベンチで上位の3モデル。Argon はセキュリティ監査の実績（Wiz）も公表 [A1][G1]
- Sonnet 5.5 / GPT-6.1 Sol / Grok 4.7: $2 前後の入力単価で大量の差分レビューを回せる [A4][O1][X1]
- Muse Wonder（検討、表外）: レビュー専用の公式ベンチはなく、Terminal-Bench と AA Index では上位3に入らない

**オーケストレーション**

- GPT-6 Astra: AutomationBench 41.4% と表中最高 [A1]
- Gemini 4 Argon: Antigravity でのマルチエージェントループの事例が多い [G1]
- GPT-6.1 Sol: 安価でエージェント向け。AutomationBench では medium effort で Opus を 2.2 ポイント上回ると公式が主張 [O4]
- Haiku 5.5（Claude 限定）: Anthropic 自身が Opus/Sonnet のサブエージェントとして推奨 [A3]
- Muse Wonder（検討、表外）: AutomationBench-AA 39.1 は Astra 41.6 / Opus 41.2 の直後。Full は 45.4 で首位だが API がない [M1]

**A との比較と提案（設定は変更していない）**
- 判断・文章と最難タスクを Opus 5.5、実装系を Grok 4.7 に割り当てる既定値は、A の結果とおおむね合っている。
- 提案1: arena / architect / interrogate のパネルに **Gemini 4 Argon**（`gemini-4-argon-high` など）を3本目として加える案。家族の違うモデルを足せば多様性が上がり、導入価格（〜11/30）のうちは費用も抑えられる。使える slug を確認してからにする。
- 提案2: swarm workers のうち狭い範囲の作業（要約・調べもの）には **Claude Haiku 5.5** を試す価値がある（$0.10/$0.50）。
- 提案3: interrogate reviewers に GPT 系（GPT-6.1 Sol）を加え、レビューの観点を増やす。
- 提案4: **Claude Sonnet 5.5** が Terminal-Bench で Opus 5.5 を上回った（70.6% vs 66.4%）ため、コーディング系（feature / bug-fix / hillclimb）で `claude-sonnet-5-5-xhigh` を試す価値がある。
- 提案5（今週追加）: arena / architect のパネルに **Muse Wonder**（`muse-wonder-1.0-xhigh`）を加える案。Opus / Grok とは家族が違い、超長期 SWE での公式比較が強い。API 単価は Opus と同じ $4/$20 なので、導入価格中の Argon よりは高い。
