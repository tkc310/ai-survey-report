### 各行の理由

- **文章作成・判断**: フラッグシップ先頭は Fable 5.2（xHigh）。Remote Labor Index は High で 41.3%（Opus 5.5 は 21.3%）、Humanity’s Last Exam（ツールあり）は 74.2%。日常の第一選択は公式が Opus 5.5 のまま。コスパは API 既定の Sonnet 5.5（High、$2/$10）を先頭に、Terra（$1/$5）と Sol（$2/$10）を続ける。今週、この枠を動かす新しい公式ベンチは無かった。[A7][A1][A4][O7]
- **コーディング**: WebDev Arena（ページの最終更新表示は 11/11）は Fable 5.2（xHigh）1838、Opus 5.5（Max）1815、Sonnet 5.5（xHigh）1772 のまま。FrontierCode 2.0 も xHigh の 49.1% が、公式が比べた公開モデルでは最高。コスパは同じ $2/$10 帯の Sonnet（xHigh。High は 1715 で 9位）、Sol（Max、1743 の 6位）、導入価格中の Carbon（High、1768 の暫定 4位。11/30 まで $2/$10）。[A7][W1][G7]
- **複雑なコーディング**: FrontierSWE v2 は Fable 69.9%、Astra 65.5%、Opus 62.3%、Carbon 61.2%。長い工程の検証では Carbon の AutomationBench 53.9% が Fable 51.4% を上回る。コスパ先頭の Carbon は 12/1 以降 $4/$20 になるので、導入価格のあいだの位置づけ。Sol と Sonnet（xHigh）が続く。[A7][G7][O1]
- **レビュー**: 専用の公開ベンチは無く、上のコーディング系と Carbon の長時間検証を根拠にする。大量の差分は入力単価 $2 前後の Sonnet（xHigh）、Sol（Max）、導入価格中の Carbon（High）。セルは前号のまま。[A7][G7][W1]
- **オーケストレーション**: OSWorld 2.1（オフライン、部分点）は Fable 89.3% が表中最高、AutomationBench は Carbon 53.9% が表中最高。コスパは導入価格の Carbon、コンピュータ操作の単価が低い Terra（$1/$5）、Sol。Google は Antigravity の Orchestrator で Carbon と Hydrogen の併用を案内しているが、Hydrogen 単体は下の見送りのとおり表に入れない。[A7][G7]
- **デザイン**: 1位が分かれるので併記する。エージェント型の WebDev は Fable 5.2（xHigh）が 1838 の 1位。UI Component は Astra（xhigh）が 1401 の 1位。Website（HTML、非エージェント）は Muse Wonder（max）が 1378 の 1位。コスパは WebDev 3位かつ UI 2位の Sonnet 5.5（xHigh、$2/$10）、総合 3位の Sol（Max）、Website 2位の Spark 1.3（xhigh、$1.25/$4.25）。Claude 内の WebDev は Fable（xHigh）> Opus（Max）> Sonnet（xHigh）。出典は [W1][D1][D2][D3][A4][M5]。
